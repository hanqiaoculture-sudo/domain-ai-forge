# Security Policy

Domain AI Forge is designed for vertical AI workflows, so security issues may involve prompts, tools, private data, model outputs, and evaluation artifacts.

Please do not open public issues for sensitive vulnerabilities. Instead, contact the maintainers privately once a security contact is published for the repository.

## Areas We Care About

- Leakage of private domain data
- Unsafe tool execution
- Prompt injection in agent workflows
- Evaluation data contamination
- Insecure adapter defaults
- Accidental credential exposure

## Current Status

This project is pre-1.0. Public APIs and adapter interfaces may change as the security model matures.
