# GitHub Launch Playbook

This playbook is written for a high-ambition open-source launch. A 100k-star target requires a project that is useful, easy to understand, visually memorable, and community-shaped.

## Positioning

Use this one-liner:

> Domain AI Forge is the open framework for optimizing vertical AI systems with model adapters, domain harnesses, and measurable multi-agent workflows.

Chinese one-liner:

> Domain AI Forge 是一个垂域 AI 优化框架，用 model adapter、domain harness 和 multi-agent workflow 把 AI 应用从 demo 推到可评测、可复盘、可迭代。

## Launch Assets

- A 3-minute runnable demo
- A 60-second architecture GIF or short video
- A crisp README with one diagram
- One strong example domain
- A roadmap that invites contributors
- Issue templates for domain packs, scorers, and adapters
- A public benchmark table once enough examples exist

## Star Growth Loops

### 1. Developer Loop

Developers star the repo when they can run something immediately and see how to extend it.

Action:

- Keep the core dependency-free.
- Make examples work without API keys.
- Add adapters as optional packages.

### 2. Founder Loop

Founders star the repo when it names the thing they are trying to build.

Action:

- Use language like "from demo to measurable vertical AI system".
- Publish domain AI teardown posts using the framework.

### 3. Research Loop

Researchers star the repo when the harness and benchmark format become reusable.

Action:

- Add transparent scoring.
- Publish domain benchmark reports.
- Support reproducible run artifacts.

### 4. Community Loop

Contributors star the repo when they can add a small domain pack and feel ownership.

Action:

- Make domain packs small and reviewable.
- Highlight contributors in release notes.
- Maintain a public domain pack registry.
